# Changelog Palm

All notable changes to this theme, grouped by topic. New entries go into the "Unreleased" section at the top; on deployment it gets the date and the branch.

Sections per version: Features, Security, Bugs, Removed, Maintenance (omit empty sections).

## Unreleased (branch `20261005_rewrite`)

### Features
- Single directory components (SDC) in `components/`, starting with the atom `palm:button` (variants primary, reversed, danger, promo, ghost, white, disabled; optional icon at the start or end)
- Buy, download, header promo, footer cancellation and issue teaser buttons use `palm:button`
- Storybook as living styleguide: stories are written in Twig next to the components and rendered by Drupal (`drupal/storybook`)
- Design tokens as CSS custom properties (`css/tokens.css`)
- Cascade layers `drupal`, `legacy` and `components`: components win over the legacy styles without specificity fights
- Styling of the remove button in the cart form (now a submit button instead of a link)

### Maintenance
- Compatibility with Drupal 11; the components (SDC variants) are tested with Drupal 11.4 only
- The CSS of normalize, Classy, EU Cookie Compliance and CAPTCHA is loaded from `css/drupal-layer.css` in the layer `drupal` (generated by `make drupal-layer`), the originals are removed via `libraries-override`
- `bundle/palm.css` is built into the layer `legacy` by blaetter-theme
- Style diff (`make style-capture`, `make style-compare`) as regression test for CSS changes, optionally logged in with a role
- npm runs only in Docker containers (`docker-compose.yml`, `Makefile`) without access to the home directory, SSH keys or `settings.php`; packages are installed from the lockfile without install scripts
- README with the development workflow
